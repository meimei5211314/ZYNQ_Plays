45.2传统串行总线精要

① RS-485 物理层（无数协议的载体）

参数规范/惯例工程备注
电气差分 A/B，±200mV 阈值；共模 -7~+12V差分抗共模干扰是长距离的根基
速率×距离10Mbps@15m ~ 100kbps@1200m「速率距离积」近似守恒
拓扑/节点手拉手总线型 ≤32 单位负载（1/8 收发器可到256）星型接法=反射灾难，必须避免
终端匹配两端 120Ω 终端 + 偏置电阻(A上拉B下拉 560~680Ω)空闲态电平不确定 → 错误起始位（排故高频点）
隔离工业品标配磁耦/光耦隔离 + 瞬态防护两地电位差烧 485 口是最常见事故

② Modbus RTU 要点补全（32章之外的现场视角）

  • 一主多从，从站地址 1~247；广播（0）只写不答；
  • 帧间静默 ≥3.5 字符 = 帧边界；字符间 >1.5 字符即帧错 —— 波特率越低窗口越宽；
  • 诊断三板斧：CRC 校验失败率、异常码分布（02 越界=点表配错）、响应超时统计（从站忙/掉线）。

③ CAN 与 CANopen

  • CAN 帧结构：SOF + 11/29 位仲裁 ID + 控制段 + 0~8B 数据 + 15 位 CRC + ACK/EOF；显性 0 覆盖隐性 1 → ID 小者胜出的非破坏仲裁；
  • 错误管理：发送错误计数器 TEC/接收 REC，>128 error passive，>255 bus-off 关闭自身（需软件复位恢复）—— 排故必查项；
  • CANopen：对象字典 OD（索引/子索引寻址参数）+ NMT 网络管理 + SDO（配置，分段传）+ PDO（实时过程数据，映射可配）；伺服/IO 模块的事实标准之一；
  • CAN FD：数据段扩至 64B、速率最高 5~8Mbps —— 新一代驱动器在迁移。

④ Profibus-DP 与 HART 一句话画像

Profibus-DP：主从+令牌混合，DB9 接头内置终端电阻开关，DP-V0 周期数据 / V1 带参数通道，12Mbps 经典；HART：在 4~20mA 上叠加 1200/2200Hz FSK 数字信号，仪表调试利器（配手持终端读变送器参数）。

45.3工业以太网三大流派 ★（核心考点）

流派/机制代表协议实时原理周期/抖动同步精度
标准以太网+优先级调度Modbus TCP、EtherNet/IP(CIP)TCP/UDP + QoS，靠交换缓存容忍延迟10ms级/无保证NTP 级
软实时 RT 帧PROFINET RT(Class 1)VLAN 优先级+专用协议栈绕过 TCP/IP250μs~ms 级~ms
硬实时（时间同步+旁路处理）EtherCAT、POWERLINK、PROFINET IRT、SERCOS III见下文 EtherCAT 原理≤100μs / <1μs 抖动<1μs(EtherCAT DC)
确定性网络标准TSN(802.1 Qbv/Qbu/AS)时间门控调度+帧抢占+gPTP 全网同步μs 级可控±1μs 内

EtherCAT 为什么快？（面试高频）

  • 「飞行读写」：一个以太网帧穿越所有从站，每个从站用专用硬件(FPGA ESC)在帧经过时纳秒级就地提取/插入自己的数据并转发 —— 不存储转发、不解析完整帧；
  • 100 台设备仍只需一帧 → 帧利用率极高，典型周期 50~500μs；
  • 分布式时钟 DC：参考时钟随帧传播，各站测量传播延迟补偿偏移，同步误差 ≪1μs —— 多轴插补的基础；
  • 代价：从站需专用 ESC 芯片/核（ET1100/LAN9252/ZYNQ 可软实现），主站栈（SOEM 开源）跑在普通网卡即可。

45.4OPC UA 与 TSN：下一代信息主线

OPC UA 解决「语义」：信息模型（变量类型/方法/事件）+ 安全内建（证书/加密）+ 传输无关（二进制/HTTP/PubSub）。TSN 解决「管道」：802.1Qbv 时间门控给关键流留时隙、Qbu 帧抢占防大帧阻塞、AS(gPTP) 全网 ±1μs 同步。两者组合 OPC UA over TSN 是控制器↔控制器、跨厂商互操作的战略方向 —— 学习顺序建议：先吃透 EtherCAT 模型，再理解 TSN 是其思想的标准化泛化。

常见问题 FAQ（避坑指南）

Q1：485 总线挂上第三台设备就不通了？

按概率：① 星型分支造成反射（改手拉手或加中继）；② 第三台地址冲突；③ 终端电阻过多（只在物理两端装，中间设备禁止启用）；④ 某设备收发器损坏拉死总线（逐一拔除定位）。示波器看 A-B 差分波形立判物理层好坏。

Q2：CAN 通信偶发中断后自动恢复又复发？

查 dmesg/寄存器 TEC/REC 计数：反复 bus-off 说明线上持续错误帧。根因 Top3：波特率采样点不一致（统一 87.5%）、线缆过长未降速、某节点地电位漂移（测对地电压）。恢复策略应指数退避而非立即重启。

Q3：EtherCAT 和办公网能不能共用交换机？

不能直接混接。EtherCAT 帧被普通交换机会「存储转发」破坏实时性且无法通过。正确做法：物理分网，或在支持协议感知的边缘做受控网关。VLAN 隔离只能防广播不能保实时。

45.6深潜：CAN 错误处理机制全景

要素说明
位填充5个同极性位后自动插反极性位(保证同步沿)；错误帧/过载帧不填充——解码器需识别
错误类型位错误/填充错/CRC错/形式错/ACK错 → 任一节点检测到即发错误标志(6个显性位)
主动 vs 被动TEC/REC≤127 主动错误(发显性标志); >128 被动(发隐性标志,不破坏总线) —— 新入网设备从被动起步? 实际上电为主动，异常降级
Bus-off 恢复TEC>255 强制脱离；标准恢复=检测128×11连续隐性位后复位发送逻辑（软件可加速但勿立即重入）

45.8深潜：CoE 对象字典到 PDO 的映射链

  1. 对象字典 OD：0x1000 通信参数 / 0x6000+厂商 profile（如 CiA402 伺服：0x6040 控制字、0x607A 目标位置）；
  2. TX/RX PDO 映射对象（0x1A00/0x1600）声明「本周期数据由哪些 OD 条目打包」；
  3. SM 通道分配 PDO → ESC 硬件按 SM 配置在帧中就地读写；
  4. 运行期改映射必须先退 SAFE-OP —— 与 47 章 EtherCAT 抓包对照阅读，帧内每个字节都能溯源到 OD 条目。

45.9深潜：Modbus ASCII 帧（冷知识但会考）

':' + 冒号起始 + 每字节两位ASCII十六进制 + LRC(8位累加和取补) + CR/LF。效率只有 RTU 一半，现存于老仪表。LRC 计算 = 所有字节和取负再取低8位 —— 面试区分度题。

45.10深潜：PTP/BMCA 三行原理

gPTP/1588 通过 Best Master Clock Algorithm 选出全网最优时钟（优先级/时钟精度/路径跳数比较），随后 Sync/Follow_Up 与 Delay_Req 测量各链路传播延迟并补偿 —— EtherCAT DC 是其硬件化特例。理解「测量延迟→补偿偏移」这一对动作，即可通吃所有时间同步协议。

45.11深潜：POWERLINK 协议原理 ★

POWERLINK（EPSG 维护，openPOWERLINK 为 BSD 开源实现）是与 EtherCAT 齐名的硬实时工业以太网，其最大特色：基于标准以太网帧、纯软件可实现、无需专用芯片。

① 体系结构与节点角色

概念说明
MN (Managing Node)管理节点=主站（PLC/控制器），发起轮询、分配时隙
CN (Controlled Node)受控节点=从站（IO/驱动），被动响应
对象字典 OD复用 CANopen 行规体系（EDS 描述设备）——迁移 CANopen 应用成本极低

② 一个通信周期的帧序列（核心机制）

TEXT
│SoC│ PReq1→CN1 │←Pres1│ PReq2→CN2 │←Pres2│ ... │ 异步段(ASnd/UDP) │SoA│
 ▲                                                                 ▲
 └ MN 广播同步起始(所有CN以此对齐时钟)        MN 广播下一周期参数/轮询计划 ┘
/* 关键设计:
· Pres(Poll Response) 是"广播"——CN1 的响应全体可见, 生产者消费者模型,
  N 节点数据在 N+1 帧内全部流转, 帧利用率随规模线性优
· 多路复用(Multiplexed): 慢速 CN 每 K 个周期才被轮询一次 → 周期内可挂更多节点
· 异步段承载标准 TCP/IP(诊断/组态) —— 与实时流共享同一网线但时分隔离 */
时间指标: 周期典型 200μs~10ms; 抖动 <1μs; 同步精度 ≈<<1μs(SoC 对齐)
EthType = 0x88AB (Wireshark 原生解析)

③ 与 EtherCAT 对照表（选型必背）

维度POWERLINKEtherCAT
开放性BSD 开源栈, 无授权费主站开源, 从站需 ESC 芯片/授权技术
从站硬件门槛任意 MCU+标准 MAC 可软实现必须 ESC 硬件(FPGA 或专用芯片)
最小周期/规模上限~200μs / 数百节点(复用后更多)~30-100μs / 65535 节点
同步机制SoC 时间对齐(精度<<1μs)DC 分布式时钟(±<1μs)
拓扑星型经交换机 / HUB? 支持环冗余(MN/CN 冗余+双网)线型菊花链天然, 分支需分支器
生态代表贝加莱(B&R 主导)、部分国产中型 PLC倍福主导, 生态最广
本质差异一句话EtherCAT 把智能放从站芯片；POWERLINK 把智能放软件栈——前者性能极致, 后者门槛极低。

「等协议」速览：SERCOS III（光纤环、伺服血统）、CC-Link IE Field（三菱系 GB 千兆）、FL-net（日系互操作）——掌握 POWERLINK 与 EtherCAT 两套模型后，这些只需对照帧结构差异即可快速上手。

45.12深潜：openPOWERLINK 在 ZYNQ 上的实现与应用

① 栈分层与三种部署形态

TEXT
openPOWERLINK v2.x 分层:
┌────────────────────────────────────┐
│ 应用层 API (process image 交换接口)  │
├────────────────────────────────────┤
│ 协议内核 DLL (Data Link Layer)      │ ← NMT状态机/OD/PDO映射/SDO

ZYNQ 三种形态:
A) 全软件: PS GEM + 用户态栈          → 周期 ~1ms   (入门/验证)
B) PL openMAC + 内核驱动              → 200~500μs  (推荐教学路线)★
C) PL 完整硬件加速(控制+MAC)          → <100μs     (产品形态)

② 形态 B 移植要点（领航者实战路径）

  1. PL 工程加入 openMAC IP（openPOWERLINK 附带）+ 双端口 RAM 存取驱动层交换区；
  2. PS 编译 openPOWERLINK 内核驱动模块（配置 CFG_DEMO_BOARD=zynq? DEMO_ZYNQ_ARM 模板），加载后经 /dev/powerlink? 字符通道与用户态 API 库交互；
  3. MN 应用：调用 oplk_create()→oplk_execNmtState? oplk_execNmtCommand 系列，过程映像用 oplk_linkProcessImage? 绑定；CN 应用更简：初始化→回调收发；
  4. Linux 侧与本课程 PLC 运行时集成：把 POWERLINK 过程映像桥接到 g_img 映像区（29章）——你的软 PLC 即获得 POWERLINK 主站能力。

③ 应用与调试

  • 应用版图：B&R 全线控制器、国内多家中型 PLC 与伺服厂；适合「想自研实时总线又不想被芯片绑定」的团队 —— 与本课程自研精神高度契合；
  • 调试：Wireshark 直接解析 SoC/PReq/Pres 帧（对照②的帧序列读时序）；openPOWERLINK 自带 trace/event 日志；CN 掉线先看 NMT 状态与 Pres 超时计数；
  • 验收实验 L45-2：MN(ZYNQ)+CN(PC 双网卡软 CN) 组网，示波器测 SoC 周期抖动 ≤1μs；故意拔 CN 观察隔离与恢复流程。
