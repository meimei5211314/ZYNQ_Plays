D1 系统层级与角色

缩写全称一句话说明
PLCProgrammable Logic Controller可编程逻辑控制器，工业控制核心
HMIHuman Machine Interface人机界面触摸屏/操作面板
SCADASupervisory Control And Data Acquisition上位监控系统（组态软件+数据采集）
DCSDistributed Control System分布式控制系统，流程行业大型控制体系
MESManufacturing Execution System制造执行系统（生产排程/追溯），位于控制与管理之间
OEEOverall Equipment Effectiveness设备综合效率 = 可用率×性能率×良品率
SOESequence Of Events事件顺序记录（ms 级时标，事故分析依据）
RTURemote Terminal Unit远程终端单元（油气/水利等远端站）
P&IDPiping & Instrumentation Diagram管道仪表流程图——控制点表的源头文档

D2 编程与运行（IEC 61131-3）

术语说明
LD / FBD / ST / IL / SFC梯形图/功能块图/结构化文本/指令表/顺序功能图 五大语言
Rung / Network梯形图的"一行"逻辑单元；网络为编译与执行的最小分组
Cycle / Scan Time扫描周期：读输入→解算→写输出 的单轮耗时
Retain 变量掉电保持区变量（超电容/Flash 支持）
Cold / Warm Restart冷启动(清非保持量)/热启动(保留保持量继续)
Force 强制调试期覆盖物理 IO 值；上线前必须解除并审计！
Task / Priority Class任务与优先级等级（如西门子 OB 循环/中断组织块思想）
FB / FC / DB功能块(有实例存储)/函数(无状态)/数据块 —— TIA 体系概念

D3 回路与过程控制

缩写全称一句话说明
PIDProportional-Integral-Derivative比例积分微分调节器
PV / SP / CV(OP)Process Variable / Setpoint / Control Variable过程量/设定值/控制输出
Cascade-串级控制：外环输出作内环 SP
Split Range-分程控制：一个 CV 分段驱动多个阀
Deadband / Hysteresis-死区/回差——防执行器频繁抖动的滞环
Two-wire Transmitter-两线制变送器：4~20mA 同时供电+传信

HFTHardware Fault Tolerance硬件故障裕度 N
SFF / DCSafe Failure Fraction / Diagnostic Coverage安全失效分数/诊断覆盖率
LOPALayer of Protection Analysis保护层分析——SIL 定级方法
MooNM-out-of-N 表决N 取 M 结构（1oo2/2oo3…）

PLPerformance LevelISO 13849 机械安全的等级(a~e)，与 SIL 对应换算
MTTFdMean Time To dangerous failure平均危险失效时间（机械安全用）
ESD / F&GEmergency Shutdown / Fire & Gas紧急停车系统/火气系统（SIS 典型应用）

D8 实时性概念

术语说明
