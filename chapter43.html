43.2DI 模块：现场信号如何安全进入系统

要点设计规范（行业惯例）原因
输入电压等级24VDC 为绝对主流（PNP 常开型占 80%+）；干接点 vs 有源接点要区分与传感器/按钮生态兼容；24V 在安全电压范围且抗干扰裕量大
电气隔离每路或每 4/8 路一组光耦（如 TLP291），前后完全独立地现场地可能漂移数十伏；隔离是设备存活的第一道墙
限流与保护串联电阻按 LED 电流计算（24V→~5mA）；TVS/压敏电阻吸收浪涌；RC 滤波或施密特整形IEC 61131-2 要求承受一定能量的浪涌（如 1.2/50μs 波形）
三线制接近开关处理 PNP/NPN 接法差异，输入极性反接保护（二极管桥或防反 MOS）现场接线错误是售后 Top 故障
滤波参数硬件 RC ~1ms + 数字滤波可配(0~99ms)，默认 10ms继电器触点抖动可达数 ms；对应本课程 PL 去抖引擎的工程出处

43.3DO 模块：驱动现场执行器的两种流派

  • 晶体管输出（24VDC）：高边驱动 P-MOS 或集成高端开关（BTS系列），带短路保护/过热关断/诊断回读；响应快（μs 级）、寿命无限长 —— 新一代小型 PLC 主流；
  • 继电器输出：触点隔离 AC/DC 通用（2A 典型），但机械寿命 ~10⁵ 次、响应 ms 级 —— 驱动接触器线圈等大功率场合仍不可替代。必须加灭弧回路（DC 并续流二极管 / AC 并 RC 浪涌吸收器）否则触点烧蚀+干扰全柜；
  • 公共点分组（每组独立 COM）便于不同电压混配；保险丝分组熔断 + 熔断检测上报（进阶功能）。

43.4AI/AO 模块：模拟量前端的门道

环节设计内容关键决策
信号类型0~10V / ±10V / 0(4)~20mA / 热电偶mV / RTD电阻4~20mA 两线制变送器是工业之王：电流传输抗长线压降，4mA 活零点兼作断线检测
信号调理分压/采样电阻(0.1%精度)→RC抗混叠→运放缓冲→可选隔离放大器(AMC1301类)或线性光耦共模抑制比 CMR >100dB@50Hz 才能对抗现场共模干扰
ADC 选型16bit Σ-Δ 型（如 ADS1148：内置PGA/激励源，RTD直连）为主流；分辨率≠精度，关注 INL/噪声峰峰采样率 10~1kSPS 足够过程量；转换时间影响 AI 更新率规格
软件标定两点标定存 EEPROM：y=kx+b 工程量换算 + 断线/超程诊断标志出厂标定数据是产品资产，随版本管理（呼应34章）
AO 输出DAC→运放缓冲→V/I 转换(0~20mA)；输出短路保护+回读校验执行器侧同样需要隔离与保护

43.6EMC 与可靠性设计清单（研发评审用）

  • 接地：PE 保护地/信号地/屏蔽地三套系统，机柜内星型接地，杜绝接地环路（46章排故案例伏笔）；
  • 屏蔽：模拟信号双绞屏蔽线，屏蔽层单端接信号地；动力电缆与信号电缆分槽 ≥20cm 或垂直交叉；
  • 浪涌/EFT：所有对外端口按 IEC 61000-4 系列（4=EFT、5=浪涌、6=射频传导）预留防护位不贴件；
  • PCB：模拟/数字分区、完整参考平面、晶振包地、复位走线远离干扰源；
  • 温度：工业级 -40~+70℃（板卡实际按器件降额），电解电容寿命是短板 → 用固态或留足纹波电流裕量；
  • 看门狗与上电时序：硬件 WDT 复位 FPGA+CPLD 监控多路电源 good 信号 —— 产品级标配。

常见问题 FAQ（避坑指南）

Q1：DI 模块现场指示灯亮但程序读不到？

分层查：LED 在光耦前还是后？前亮后灭 = 光耦/限流问题；软件读到 0 = 公共端 COM 未接（最常见！）或滤波参数把短脉冲滤掉了。对照 46 章「现象→层次」表排查。

Q2：为什么 4~20mA 断线会显示最大值而不是 0？

活零点设计：<3.6mA 判定断线、>21mA 判定超程，0~20mA 无法区分「真 0」与「断线」。这是选活零点的根本理由 —— 安全仪表系统强制要求。

Q3：继电器输出驱动变频器/电磁阀总是误动作？

感性负载断开瞬间的反电动势可达数百伏。必须在负载两端并联灭弧器件（AC:RC 吸收器 0.47μF+47Ω 起步；DC:续流二极管）。PLC 说明书都强调却总被忽略 —— 也是 EMC 干扰邻居设备的元凶。

🧪 动手实验 L43-1：搭建「半工业」DI/DO 前端

用领航者扩展口外搭：① 光耦+限流电阻+TVS 的 24V DI 输入板（面包板即可）；② 高边 MOS 驱动 LED 模拟负载并实现短路保护验证（对地短路→自动关断）。接入你的 PLC 项目替换裸按键，用 12V/24V 适配器实测。完成后你对「工业 IO 为什么这么贵」会有切肤体会。

同一模块 PNP/NPN 混接 = COM 电平矛盾 → 半数通道常亮。设计期用分组 COM 的模块物理隔离两种制式；图纸标注「源型/吸型」并进 BOM 审查。

43.8深潜：AI 前端两个经典难题

  • 热电偶冷端补偿 CJC：热偶测量的是冷热端温差 → 必须实测接线端子温度再叠加查表。实现：模块内置 PT100 或硅基温度传感贴在端子旁，软件按 ITS-90 分度表线性化（分段折线即可达 0.5℃）；断偶检测=超量程上冲判定。
  • RTD 三线制消除引线电阻：Pt100 引线每米 ~0.4Ω×2 根会带来数℃误差。三线制用恒流源在两根引线上产生等值压降，第三线回读抵消 —— ADC 差分测 RTD 端电压时引线压降自动相减。四线制则完全消除（实验室级精度）。

43.10深潜：降额设计与 MTBF 预测入门

  • 降额曲线：电解电容 105℃ 型在 70℃ 环境寿命 ≈ 额定×e^(温差/10)？工程按每降10℃寿命翻倍估算；MOSFET 按 60% 电压/50% 电流降额；LED 按光衰 L70 定寿。
  • MTBF 预测：Telcordia SR-332 方法 I 用器件应力法逐件计算 λ=λb×πT×πQ… 汇总；Excel 模板即可完成整机预测 —— 报价阶段客户常要这份文件（呼应46章可用性算术的输入）。

43.11深潜：通讯模块 CM / CP / IM 的设计与实现 ★

模块化 PLC 的通信能力由三类模块承担（命名以西门子体系为例，其他厂商概念同构）。理解它们的差异与内部实现，是通讯模块研发岗的核心知识。

① 模块分类学与功能定位

类型代表型号定位关键特征
CPU 板载口S7-1500 集成 PN 口基础以太网通信，与扫描共用 CPU 资源无独立处理器；负载影响扫描周期
CM 通信模块CM PtP (RS232/422/485)、CM CAN OPEN扩展串行/现场总线接口协议多由 CPU 软件栈承载或轻量协处理；点对点报文通信为主
CP 通信处理器CP 1543-1、CP 343-1 Lean、CP 1243-7?自带协议处理器的智能网卡独立于 CPU 扫描运行：连接管理/加密防火墙/Web服务/FTP/SOE缓冲；CPU 停机仍保通信
IM 接口模块IM 155-6 PN ST(ET200MP 头)、IM 153-2(ET200M)、老 IM360/365分布式 IO 站点的「站点大脑」或机架互联作为 PROFINET IO 设备侧 与上级控制器对话；管理本地 IO 模块背板

一句话区分：CM 加接口、CP 加算力、IM 当代表。CP 与 CM 的本质差异是「是否有独立处理器使通信不占用 CPU 扫描资源」。

设计要点:
· 背板: S7-1500 用类 PCIe 高速背板(APL), ET200SP 用 BusAdapter;
  自研可用 SPI/并行总线 + 上电枚举协议(ID引脚编码槽位)
· 双PHY支持设备级环网(MRP); 变压器+Bob Smith端接; 隔离地
· LED组: SF(系统故障)/BF(总线故障)/Link/Act —— 状态机由固件驱动
· 独立供电域: CP 的"CPU停机仍在通信"要求其电源不受主控复位影响

③ 软件架构与实现要点（以 PROFINET IO 设备型 IM/CP 为例）

层职责实现要点
物理/链路MAC+PHY, MRP 冗余可选ZYNQ 方案: PS GEM 或 PL openMAC
实时协议RT 帧收发、VLAN优先级、DCP(发现/设名/IP)RT 帧绕过 TCP/IP 栈直通驱动层 ★
AR 连接管理建立/参数化/释放应用关系; Watchdog 因子协商超时=watchdog因子×基础时间, 超时即输出置安全态(OSS)
循环数据输入/输出 CR 镜像到过程映像双缓冲+一致性标记; 长度与组态严格一致
非循环服务记录数据读写(诊断/参数)、报警通道诊断条目带时戳入 SOE 缓冲
与 CPU 接口背板过程映像交换+参数集下载+固件升级通道版本协商: 固件不匹配拒绝组态并 LED 提示

状态机主线：上电自检 → 读槽位/参数 → DCP 等待设备名 → AR 建立握手（含组态一致性校验）→ 数据交换 → 异常回退。每个状态迁移都要更新诊断缓冲与 LED。

④ 在 ZYNQ-7020 上的映射实现（本课程延伸）

  • 自制 CP 形态：PL 实现 openMAC/MAC 卸载 + PS 跑 openPOWERLINK MN 栈（见45章）——通信独立于 Linux 业务，等效 CP 定位；
  • 自制 IM 形态：把第32章 Modbus 从站升级为 PROFINET IO 设备栈（开源 p-net），领航者变身分布式 IO 站点头；DI/DO 引擎（27章）即其背板 IO；
  • 背板实验：用 SPI/AXI 总线模拟「CPU↔CM」过程映像交换协议（槽位枚举+看门狗+镜像区），两周可做出教学版 —— 这是理解模块化 PLC 的最佳练习。

⑤ 调试要点清单

  1. LED 状态机先行：SF/BF 闪烁码即故障分类（对照手册灯语表）；
  2. 抓包三查：DCP 有无响应（设备名/IP 分配层）、RT 帧是否到达（链路层）、AR 握手在哪一步失败（协议层）；
  3. Watchdog 超时类断连：核对双方 watchdog 因子与网络负载（47章案例4同源）；
  4. 组态不一致错误码：逐一比对 IO 长度/槽位/子槽分配 —— 90% 是 GSD 组态与实际模块不符。
