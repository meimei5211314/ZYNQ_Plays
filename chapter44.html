44.1PLC 研发相关标准地图

标准号名称/范围对研发的意义
IEC 61131 系列可编程控制器族：-1总览 -2设备要求 -3编程语言 -5通信 -7模糊控制 -8指南PLC 产品的「宪法」；-2 是硬件设计输入，-3 是软件框架依据
IEC 61508 系列电气/电子/可编程电子安全系统功能安全母标准（SIL 分级）SIL2/3 级安全 PLC 的设计依据；衍生 ISO 26262(汽车)/IEC 61511(过程)
IEC 61158 / 61784工业通信网络现场总线 / 行规集（CP 1~27 对应各总线）第45章总线协议的标准出处
IEC 62443 系列工业过程测量控制信息安全（原 ISA-99）工控安全设计框架：Zone/Conduit/SL 等级
IEC 61000 系列EMC 试验与测量技术（-4-x 抗扰度各分项）硬件 EMC 设计与测试的判卷标准
GB/T 国标GB/T 15969(对应61131)、GB/T 20438(对应61508)、GB/T 33008等国内市场准入与招投标技术依据
UL 508 / EN 60204北美工业控制设备安全 / 机械电气安全出口北美/欧洲的强制门槛

44.2IEC 61131-2 设备要求速览（硬件研发输入）

  • 工作条件：开放式/面板式/封闭式设备分级；温度 5~55℃（室内）起步，存储 -40~+70℃；湿度 5~95%RH 无凝露；
  • 电气要求：24VDC 额定允许波动范围、绝缘耐压（如 500V AC 试验电压按工作电压等级）、保护接地连续性；
  • 机械要求：振动/冲击试验等级、导轨安装保持力；
  • EMC：引用 IEC 61000-4-2(ESD ±8kV接触)/-3(射频场)/-4(EFT ±2kV)/-5(浪涌 1kV)/-6，判定准则 A/B/C（性能降级允许程度）；
  • 研发落地方式：把每条要求翻译成设计规格表（如 EFT ±2kV → 每端口 TVS+共模电感），评审逐条打勾。

44.3功能安全（IEC 61508）核心概念 ★

① 基本链条

危险分析(H&RA) → 定义SIF 安全仪表功能（如"锅炉超压则切断燃料阀"）→ 用 LOPA/风险矩阵确定所需 SIL 等级 → 设计实现并验证达到该等级 → 运行期维护证明持续有效。

② SIL 等级的数学含义

等级低要求模式 PFDavg高要求/连续模式 PFH (1/h)风险降低因子典型应用
SIL110⁻² ~ 10⁻¹10⁻⁶ ~ 10⁻⁵10~100一般联锁
SIL210⁻³ ~ 10⁻²10⁻⁷ ~ 10⁻⁶100~1000机械安全、过程多数场景
SIL310⁻⁴ ~ 10⁻³10⁻⁸ ~ 10⁻⁷1000~10000锅炉保护、透平跳闸
SIL410⁻⁵ ~ 10⁻⁴10⁻⁹ ~ 10⁻⁸10⁴~10⁵极罕见（核/铁路）

③ 硬件结构约束：HFT 与表决

  • HFT（硬件故障裕度）：容忍 N 个危险故障仍保持安全的能力。SIL2 至少 HFT0(低SFF)或 HFT1；SIL3 更严；
  • 典型冗余结构：1oo1单通道 / 1oo2（任一动作即输出安全，防拒动）/ 2oo2（都动作才输出，防误动）/ 2oo3 三取二（兼顾两者，安全 PLC 经典架构）；
  • SFF 安全失效分数 =（安全失效+可诊断危险失效）/总失效。提高 SFF 靠诊断覆盖率 DC：看门狗、存储器CRC、IO 回读、ADC 注入自检、时钟监测……诊断是安全设计的灵魂；
  • 共因失效 CCF：两通道用同一电源/同一软件 bug → 冗余形同虚设。对策：通道物理隔离、多样性设计（不同算法/不同芯片）、β 因子评估。

④ PFD 验证计算（感受一下数学）

TEXT
1oo1 教学近似：PFDavg ≈ λDU × T / 2
仅在定失效率、小概率、完全证明测试与恢复等假设下使用。
多通道需另建包含独立性、共因、测试与维修的模型。
例：500 FIT × 8760 h / 2 = 0.00219，无量纲。
仅靠该数值不能判定完整安全功能的 SIL。

⑤ 软件与流程要求（61508-3）

  • V 模型全生命周期文档：需求→架构→详细设计→编码→单元/集成/验证测试，每步可追溯；
  • 编码规范（MISRA C）、静态分析、MC/DC 覆盖率（SIL3）、受控工具链（T3 类工具需论证或认证）；
  • 这就是 SIL 级安全 PLC（如西门子 F 系列）价格数倍于标准型的根本原因：买的是整个开发过程与证据链。

44.4认证实操：CE / UL / CCC 怎么走

认证市场核心指令/标准模式
CE-EMC欧盟2014/30/EU + EN 61131-2自我声明 + 技术文档留存（可公告机构增强公信）
CE-LVD/RoHS欧盟2014/35/EU / 2011/65/EU同上
UL 508 / 61010北美UL 实验室工厂审查+型式试验强制第三方 + 年度厂检
CCC/CR 认证中国对应国标目录内产品目录内强制
功能安全认证全球TÜV Rheinland/Süd、exida 等按 61508 认证产品+流程，周期 1~2 年

送测前自检清单：EMC 预测试（找实验室摸底）、耐压绝缘设计余量、说明书安全警示语、关键件清单(CDF)与 UL 认证件选用、铭牌参数合规。

44.5IEC 62443 工控信息安全入门

  • Zone & Conduit 模型：把系统划分为安全区域（Zone）与受控通道（Conduit），每区/道评估并指定 SL1~SL4 安全等级；
  • 对设备商的要求（62443-4-1/4-2）：安全开发生命周期（SDL）+ 组件技术要求（如最小权限、输入校验、审计日志、安全启动）；
  • 与第33章 Web 监控的「Known Limitations」呼应：产品化路线 = HTTPS+账号体系+审计日志+网络分区，正是朝 SL1/SL2 靠拢。

常见问题 FAQ（避坑指南）

Q1：自研设备到底要不要做功能安全认证？

取决于用途：设备用于安全相关回路（客户 SIS 系统里）→ 必须有 SIL 认证否则投标出局；仅做普通控制 → 不强制，但按 61508 思路设计（诊断+看门狗+安全输出态）能显著提升可靠性并是极好的卖点。先问销售场景再定投入。

Q2：SIL2 和 SIL3 的成本差多少？

经验量级：SIL2 认证投入百万级人民币、周期约1年；SIL3 需要更严的冗余结构+MC/DC 覆盖+更重的文档与独立评估，投入翻数倍。所以市场上 SIL3 产品稀缺且贵。

Q3：IEC 61508 与 ISO 26262 / IEC 61511 什么关系？

61508 是母标准；26262=汽车行业改编（ASIL A~D 分级）；61511=过程工业应用改编（SIS 系统生命周期，只允许用已认证设备）；机械安全对应 ISO 13849（PL 等级 Performance Level）。答题时能画出这棵衍生树即显专业。

44.6 定量练习：先列假设，不凭数值宣称 SIL

先用单通道 1oo1 理解验证测试周期的影响。假设危险未检出失效率为常数、λDU×T 很小、证明测试能完全发现潜伏故障、测试后完全恢复、忽略测试停机与修复时间，则可近似：

TEXT
PFDavg ≈ λDU × T / 2
练习设定：λDU = 500 FIT = 5×10^-7 /h，T = 8760 h
PFDavg ≈ 0.00219（无量纲）
T 缩短一半，其他假设不变，近似值也缩短一半。
这是单个简化模型的数值，不是整套安全功能的等级证书。

多通道模型须交代投票架构、测试是否同步、独立性、共因、诊断、维修和完整功能边界。把未说明的 2oo3 系数、问号与区间猜测留在“完整算例”里会误导，因此改为可手算核对的基础练习。SIL 还涉及架构与系统能力及生命周期证据。

标准适用范围以现行正式文本和项目合规依据为准：IEC 功能安全资料入口。

44.7深潜：软件工具置信度分类（T1/T2/T3）

类定义例子要求
T1不影响输出(编辑器/版本管理)Vim, Git, diff基本验证即可
T2可能有错但可发现/规避编译器、静态分析器、示波器按使用说明+确认测试
T3错误直接进产品且难以发现代码生成器(如 IEC 编程IDE的代码生成)、仿真模型转换器需按 T3 类开发论证或已有认证 ★

44.8深潜：防爆入门——分区与 Ex 标志解读

TEXT
区域划分(气体): Zone0(连续存在) Zone1(正常可能) Zone2(异常短时)
设备标志例: Ex II 2G Ex db IIB T4 Gb
  II=非矿用  2G=Zone1适用
  db=隔爆外壳(保护型式; 另有 ia本质安全/in正压/mi浇封…)
  IIB=气体组(氢气属IIC更严)  T4=表面温度组(≤135℃)
本安设计核心: 火花+热表面能量双双限制 → 储能元件(L/C)参数与限能电阻
按 Uo/Io/Po 表匹配现场设备 —— PLC 的防爆 IO 卡即按此认证。

44.9深潜：IEC 62443-4-2 组件要求(CR)节选

  • CR1.1 认证与 CR1.2 用户管理：唯一标识+角色分级；CR2.1 最小权限；CR3.1 通信完整性(防篡改)；CR4.x 资源可用性(防 DoS：连接数/速率上限——对应33章 Web 限流)；
  • SL 定级方法：对每个威胁场景问「攻击者能力到哪级仍被防住」→ SL2 = 防内部低技能；SL3 = 防具备工控知识的小团队。产品安全声明写「支持至 SL2」比空喊「安全」专业一百倍。
