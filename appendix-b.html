B1 C 语言与编程基础

Q1 volatile 关键字的作用与三个典型场景？能替代锁吗？

【考察点】编译器优化边界。
【要点】禁止编译器对该变量缓存/重排优化，每次强制真实访存。场景：①MMIO 寄存器指针；②ISR 与主循环共享标志；③多执行流可见性基元。不能提供原子性与内存序 → 不能替代锁（对应37章）。

Q2 static 的三种用法？

【要点】①函数内 static 变量：静态存储、只初始化一次、作用域不变生命周期变；②文件级 static 函数/全局变量：内部链接，隐藏实现；③C++ 类成员另说。工程价值：模块化封装 + 避免命名污染。

Q3 判断大小端并写转换函数。

【要点】联合体或指针强转看低地址字节：int x=1; *(char*)&x==1 ? 小端 : 大端。ARM 默认小端，网络字节序大端 → htonl/ntohl 或手写移位交换。Modbus 寄存器字节序坑正源于此（32章）。

Q4 结构体对齐规则？为什么需要对齐？

【要点】成员按自身大小对齐、整体按最大成员对齐、可 packed 改变。原因：总线访问效率与原子性，非对齐访问在部分 ARM 配置直接异常。协议解析常用 __attribute__((packed)) + memcpy 而非强转指针。

Q5 写宏：置位/清位/翻转/测试第 n 位。

【要点】#define BIT(n) (1u<<(n))；SET: x |= BIT(n)；CLR: x &= ~BIT(n)；TGL: x ^= BIT(n)；TEST: (x>>n)&1。加分点：u 后缀防 int 溢出、多重求值陷阱说明。

Q6 memcpy 与 memmove 区别？手写一个安全拷贝。

【要点】memmove 处理重叠区域（判断方向后正向/反向拷贝）。追问野指针/长度校验/对齐优化路径。

Q7 堆和栈的区别？嵌入式里栈溢出有什么症状？

【要点】栈：自动分配、连续向下、快、容量小；堆：malloc 管理、碎片风险。栈溢出症状：随机跑飞/局部变量被踩/相邻任务数据互串 —— 链接脚本看栈区间 + 高水位填充(0xDEADBEEF)检测。

Q8 const int *p / int * const p / int const * const p 分别是什么？

【要点】从右向左读：指向常量的指针（内容不可改）/常量指针（指向不可改）/都不可改。记忆口诀「const 在 * 左修饰内容，在 * 右修饰指针」。

Q9 # 和 ## 在宏中的作用？写一个带 debug 等级的打印宏。

【要点】#字符串化、##拼接。示例：#define DBG(lv, fmt, ...) printf("[" #lv "]" fmt "\n", ##__VA_ARGS__)。加分：do{}while(0) 包裹多语句宏的原因。

Q10 程序的内存分区？下面各变量在哪？

【要点】text/data(已初始化)/bss(未初始化)/heap/stack。全局初值→data、未初值→bss、static 局部→data、字符串字面量→rodata、malloc→heap。追问 bss 为何不占镜像体积（运行时清零）。

B2 Linux 系统编程

Q11 进程与线程的区别？嵌入式里怎么选？

【要点】资源/地址空间隔离度、切换开销、通信成本对比。选择：需要故障隔离用进程（Web 服务崩不倒扫描线程）；共享大数据高频交互用线程（PLC 运行时）。加分：clone 标志位本质。

Q12 select / poll / epoll 对比？

【要点】select fd 上限+每次全量拷贝+O(n)；poll 去掉上限仍 O(n)；epoll 红黑树注册+就绪链表回调，O(1) 且支持 ET/LT。连接数少时 poll 完全够用 —— 别为技术而技术。

Q13 什么是僵尸进程/孤儿进程？如何避免僵尸？

【要点】子进程退出父进程未 wait → 僵尸（占 PID 表项）；父先亡则由 init 收养（孤儿）。避免：signal(SIGCHLD, SIG_IGN)、waitpid(WNOHANG) 循环、两段 fork。

Q14 常见 IPC 方式对比与选型？

【要点】管道(父子)、FIFO(任意进程)、消息队列(报文边界)、共享内存(最快+需同步原语)、信号(事件通知)、socket(跨机通用)。PLC 场景答案：映像区共享内存+mutex，事件通知 eventfd/信号量。

Q15 TCP TIME_WAIT 是什么？服务器大量出现怎么办？

【要点】主动关闭方 2MSL 等待态，防旧报文串扰。缓解：SO_REUSEADDR、让客户端先关、长连接/连接池、调内核 tw_reuse（理解风险）。

Q16 什么是零拷贝？列举实现层次。

【要点】减少 CPU 参与的数据搬运：sendfile/splice（省用户态往返）、mmap+write、DMA 直接搬运（38章 HP 口）、RDMA。答出「拷贝次数+上下文切换次数」账本即高分。

B3 设备驱动专项

Q17 字符驱动的最小框架包含哪些要素？

【要点】alloc_chrdev_region+cdev_init/add+class_create+device_create → /dev 节点；file_operations 实现 open/read/write/unlocked_ioctl；module_platform_driver 注册匹配 of_match_table（对照17章代码默写）。

Q18 为什么中断上下文不能睡眠？哪些 API 因此不能用？

【要点】睡眠=调度出去，中断上下文没有可调度的 task 结构（不是进程），且必须快速返回。禁用：mutex/semaphore/kmalloc(GFP_KERNEL)/copy_to_user/msleep。替代：spinlock、GFP_ATOMIC、tasklet/workqueue 下放。

Q19 为什么必须有 copy_to_user/copy_from_user？

【要点】①用户指针不可信（校验合法性、缺页需可能睡眠的处理流程）；②用户/内核地址空间隔离（MMU 双页表），直接解引用既危险也可能根本访问不到。顺带展示 -EFAULT 返回约定。

Q20 platform 总线的匹配机制？probe 何时被调用？

【要点】设备(device)来自 DTB 枚举，驱动(of_match_table)注册时逐 compatible 比对（还支持 id_table/name 兜底），成功即 probe。追问：DT 里 status=disabled 的节点不会生成设备。

Q21 ioremap 的作用？不用它会怎样？

【要点】把物理寄存器窗口映射到内核虚拟地址并建立 non-cacheable 属性。直接解引用物理地址 = 访问的是错误虚拟地址（Oops）或命中错误映射。配套纪律：readl/writel 访问、devm_ 自动回收。

Q22 UIO 的原理与局限？（本课程 PLC 的选型依据）

【要点】内核只提供 mmap 物理窗口 + 阻塞读等 IRQ（generic-uio 自动屏蔽/再使能），业务全在用户态。优点：免内核维护、崩溃不影响内核。局限：无 DMA 子系统接入、无标准框架生态 —— 需要这些时回归字符驱动/dmaengine。

Q23 module_platform_driver() 宏展开了什么？

【要点】等价于 module_init(platform_driver_register)+module_exit(unregister) 三行糖。借此考 module 加载流程：insmod→sys_call→vermagic/SMP 校验→符号重定位(内核导出表)→init 调用。

Q24 spinlock/mutex 选型？和 ISR 共享数据怎么办？

【要点】能否睡眠是分水岭（37章决策树）。与 ISR 共享：进程侧 spin_lock_irqsave（防本地中断抢占），ISR 内裸 spin_lock；SMP 下另有跨核自旋语义由锁保证。

Q25 设备树解决了什么问题？没有它世界怎样？

【要点】硬件描述与驱动代码解耦：同一驱动二进制适配不同板卡，改板不改码。历史：arm 时代 board 文件爆炸 → DT 统一描述。追问 reg/cells/interrupts 三元组含义即回到14章表格。

Q26 用户态 mmap /dev/mem 访问寄存器与写驱动相比的优劣？（开放）

【要点】优：零开发量、调试神器(devmem)。劣：绕过权限模型(root 才可用)、无并发保护、无抽象复用、cache 属性难控。结论：调试可用，产品走驱动/UIO —— 展示工程判断力比背 API 更重要。

B4 FreeRTOS / RTOS / 微内核专项（12 题）★第48~50章配套

Q34 FreeRTOS 如何保证调度的确定性？抖动来源有哪些？

【要点】固定优先级抢占+O(1) 就绪表选任务；确定性=「最高优先级就绪即运行」。残余抖动来源：临界区关中断段、DMA/总线争用、tick 精度、cache miss。量化手段=49章运行时统计+Tracealyzer。

Q35 任务间通信方式如何选型？给出你的排序与理由。

【要点】单播事件→Task Notification(最快最省)；字节流→Stream Buffer；定界消息→Queue；多条件同步→Event Group；资源互斥→Mutex(带继承)；跨核→rpmsg。答出「通知优先于队列」是新版教材信号。

Q36 优先级反转的完整场景与 FreeRTOS 的两层对策？

【要点】低持锁-中插队-高等待。对策①互斥量优先级继承；②设计层缩短临界区/避免嵌套锁。火星探路者案例讲清「为什么测试没发现」(低概率相位)更加分。

Q37 栈溢出的两种检测机制原理与局限？

【要点】方法1：切换时检查栈顶水印字是否被写(只抓"越界即毁水印"的快速溢出)；方法2：全栈 0xA5 模式扫描(慢但全)。共同盲区：溢出瞬间已破坏内存——根治靠静态分析+高水位留 30% 裕量。

Q38 tickless idle 如何做到低功耗又不丢节拍？

【要点】进入前算最近唤醒点→停 tick 定时器→换低功耗计数器到点唤醒→补正 xTickCount(补偿睡眠期间流逝的 tick)。实现难点：低功耗定时器与 tick 源不同步的补偿逻辑（vPortSuppressTicksAndSleep）。

Q39 为什么 ISR 版 API 要多一个 xHigherPriorityTaskWoken 参数？

【要点】ISR 内不能直接调度（嵌套/现场复杂），API 只标记"有高优任务就绪"，ISR 出口 portYIELD_FROM_ISR 一次性切换——把 N 次切换合并为 1 次，且保证在正确上下文发生。

Q40 heap_4 的碎片风险怎么量化与规避？

【要点】监控 xPortGetMinimumEverFreeHeapSize 趋势；规避：启动期一次性分配(创建后不再动态)、固定尺寸池化、或全静态 xTaskCreateStatic。功能安全场景直接禁堆。

Q41 上下文切换的时间开销由什么组成？如何实测？

【要点】组成：PendSV 进出+压弹 16 寄存器+调度器选任务(C函数)。CM4 典型 1~2μs@168MHz。实测：两任务 ping-pong 写 GPIO，示波器测半周期；或 DWT->CYCCNT 差值统计。

Q42 FreeRTOS 的 SMP 模式与 AMP 部署的核心区别？

【要点】SMP：一个内核管多核，共享就绪表，自动负载均衡但核间锁开销+故障共域；AMP：每核独立内核/裸机，经 rpmsg 通信，故障隔离强、实时可控。ZYNQ 上选 AMP 的理由（40章）。

Q43 SeL4 的 Capability 与 Linux 文件描述符有何本质不同？

【要点】fd 是全局命名空间里的句柄+内核策略检查；cap 是对象引用本身携带权限、可裁剪(Mint)、可传递、无全局表查询——权限模型从"身份校验"变为"持有即授权"，最小权限可被内核强制。

Q44 SeL4 形式化验证覆盖了什么？以下哪个它不保证：A 缓冲区溢出 B 规格正确性 C 无死锁 D 实现符合抽象规格

【答案】B 与 C 不在完整性证明范围（规格对错属需求工程；无死锁非其证明目标）。A/D 属已证明性质。这题专治背概念不读原文的候选人（50章 Q1）。

Q45 CAmkES 相比手写 OpenAMP 组件的价值是什么？

【要点】声明式拓扑→自动生成 IPC glue 与 cap 分发（手写最易错的部分）；接口即契约（IDL 编译期检查）；安全策略集中可审计（50.10 的 camkes.gen.capdl）。代价：学习曲线+模板调试黑盒感。
